# Пояснення інтерфейсу SEO Аналізатора

## 📊 Результати аналізу

### Статуси конкурентів

**🟢 VALID** - Сторінка успішно проаналізована, достатньо контенту (>100 слів)
**🟠 weak** - Сторінка має мало тексту (<100 слів). Це може бути:
- Instagram/Facebook/YouTube (мало текстового контенту)
- Сторінка з динамічним контентом (JavaScript)
- Блокування боту

**🔴 N/A** - Заголовок не видобувся (помилка парсингу або редірект)

### Чому 0 слів?
- Соцмережі (Instagram, Facebook) не мають текстового контенту для парсингу
- Динамічні сайти потребують JavaScript для рендерингу
- Наш парсер бере лише статичний HTML

---

## 🔑 Ключові терміни

**Чому таблиця пуста?**
Якщо більшість конкурентів мають статус "weak" (мало тексту), система не може видобути LSI-терміни.

**Що робити?**
- Використайте інше ключове слово (напр. "львівські дріжджі рецепт")
- Або увімкніть Mock Mode для тестування: `USE_MOCK_SERP=true` в `.env.development`

---

## ✍️ Оцінка Контенту

**Як це працює:**
1. Вставте свій HTML або Markdown в редактор
2. Система автоматично оцінить (0-100 балів):
   - **Терміни (60%)** - чи використані LSI слова
   - **Структура (20%)** - кількість слів
   - **Заголовки (20%)** - H1, H2, H3

**Чому 0/100?**
Поле порожнє. Скопіюйте текст або HTML для оцінки.

**Приклад:**
```html
<h1>Львівські дріжджі</h1>
<p>Львівські дріжджі - це традиційний продукт...</p>
<h2>Як використовувати</h2>
<p>Дріжджі використовують для випічки...</p>
```

## 🤖 SEO Coach

**Чому пише "Спочатку оцініть свій контент"?**
Coach дає поради на основі вашої оцінки. Спочатку:
1. Вставте текст у редактор
2. Дочекайтеся оцінки (автоматично)
3. Натисніть **"🤖 SEO Coach"**

---

## 🤖 AI Writer

**Чому пусто?**
AI Writer потребує завершеного аналізу з VALID конкурентами.

**Що робити зараз:**
1. **Оновіть сервер** (зміни в коді вступили в силу)
2. Створіть новий аналіз з кращим ключовим словом, наприклад:
   - ❌ "львів" → занадто загальне, соцмережі в ТОП-10
   - ✅ "львівські дріжджі рецепт" → блоги, статті
3. Або використайте Mock Mode для тестування

---

## 🔧 Швидке тестування (Mock Mode)

У `.env.development` змініть:
```
USE_MOCK_SERP=true
```

Перезапустіть:
```bash
ENV=development uvicorn main:app --reload
```

Mock режим використає штучні дані для демонстрації всіх можливостей.
